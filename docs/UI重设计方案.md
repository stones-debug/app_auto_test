## 1. 设计目标

打造一个 **现代 SaaS 风格** 的测试平台 UI：
- 清爽、专业的视觉感受
- 一致的设计语言（颜色/间距/圆角/阴影）
- 良好的信息层级和操作引导
- 保留 Element Plus 组件库，仅通过样式覆盖实现

## 3. 全局导航结构（分区侧边栏 — 方案 A）

### 3.1 侧边栏设计（MainLayout — 动态渲染）

侧边栏分为 **两个区域**，中间用分隔线隔开。根据当前路由动态判断是否显示项目导航区。

#### 未进入项目时（项目列表页）

```
┌──────────────────────────┐
│  🚀 APP 自动化测试平台     │  ← Logo 区域
├──────────────────────────┤
│                          │
│  📁 项目管理   ← active   │  ← 全局导航区
│  📱 设备管理              │
│  ▶️ 执行记录              │
│  📊 报告管理              │
│                          │
├──────────────────────────┤
│  👤 admin  管理员         │  ← 底部用户信息
└──────────────────────────┘
```

#### 进入项目后（/projects/:id/* 路径）

```
┌──────────────────────────┐
│  🚀 APP 自动化测试平台     │  ← Logo 区域（不变）
├──────────────────────────┤
│  ← 返回项目列表           │  ← 项目导航区（动态出现）
│  📁 登录功能测试           │  ← 当前项目名称
├──────────────────────────┤
│  📋 用例管理   ← active   │  ← 项目子模块（高亮当前）
│  🧩 元素管理              │
│  📦 套件管理              │
│  🔧 变量管理              │
├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┤  ← 分隔线
│  📁 项目管理              │  ← 全局导航区（始终存在）
│  📱 设备管理              │
│  ▶️ 执行记录              │
│  📊 报告管理              │
├──────────────────────────┤
│  👤 admin  管理员         │  ← 底部用户信息
└──────────────────────────┘
```

### 3.2 侧边栏分区说明

| 区域 | 内容 | 何时显示 |
|------|------|----------|
| **项目导航区**（顶部） | 返回按钮 + 项目名称 + 4个子模块 | 仅在 `/projects/:id/*` 路径下显示 |
| **全局导航区**（底部） | 项目管理、设备管理、执行记录、报告管理 | 始终显示 |

### 3.3 项目子模块路由映射

| 侧边栏入口 | 路径 | 页面 |
|-----------|------|------|
| ← 返回项目列表 | `/projects` | `Project.vue` |
| 📋 用例管理 | `/projects/:id/cases` | `Case.vue` |
| 🧩 元素管理 | `/projects/:id/elements` | `Element.vue` |
| 📦 套件管理 | `/projects/:id/suites` | `Suite.vue` |
| 🔧 变量管理 | `/projects/:id/variables` | `Variable.vue` |
| 📋 用例编辑 | `/projects/:id/cases/:caseId/edit` | `CaseEditor.vue` |

### 3.4 全局导航路由映射

| 侧边栏入口 | 路径 | 页面 |
|-----------|------|------|
| 📁 项目管理 | `/projects` | `Project.vue` |
| 📱 设备管理 | `/devices` | `Device.vue` |
| ▶️ 执行记录 | `/executions` | `Execution.vue` |
| 📊 报告管理 | `/reports` | `Report.vue` |

### 3.5 交互细节

- **进入项目后**：侧边栏顶部动态插入项目导航区（返回按钮 + 项目名 + 子模块菜单）
- **返回项目列表**：点击"← 返回项目列表"回到 `/projects`
- **用例编辑页**：进入 `/projects/:id/cases/:caseId/edit` 时，侧边栏保持项目导航不变，"用例管理"仍为 active 状态
- **项目名称获取**：通过 `getProject(projectId)` API 获取，watch 路由参数变化时更新
- **全局菜单高亮**：当路径为 `/projects`（项目列表）时，"项目管理"菜单项高亮

## 4. 顶栏设计（MainLayout 顶栏）

```
┌─────────────────────────────────────────────────────────┐
│  用例管理                              🔔  👤 admin ▼   │
│  ───────────────────────────────────────────────────    │
│  （面包屑 / 页面标题，大字加粗）                           │
```

**设计要点：**
- 左侧：当前页面标题（大字、深色、加粗），从 `$route.meta.title` 获取
- 右侧：通知图标（预留） + 用户头像圆 + 下拉菜单
- 顶栏高度 64px，底部 1px 浅灰分隔线
- **不再显示水平 Tab**（已移至侧边栏）

### 5.2 设计要点

- **筛选栏**：搜索框 + 可见性 Radio Button，统一圆角背景
- **分页器**居右

### 6.5 编辑器设计要点

- 步骤/断言卡片用**左侧彩色竖线**区分（步骤蓝色、断言绿色）
- 拖拽手柄 `⠿` 放在最左侧，hover 时变主色
- 每个步骤/断言有圆形序号徽章 ① ② ③
- 删除按钮用红色文字，hover 出确认提示
- 底部固定操作栏：返回 + 保存

### 6.6 执行步骤字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 动作 | 下拉选择 | 是 | 启动APP/关闭APP/点击/输入/清空/滑动/滚动/返回/等待/截图/获取文本/获取属性/坐标点击 |
| 元素 | 元素选择器 | 条件 | sleep 时不需要 |
| 参数 | 输入框 | 否 | 根据动作类型不同 |
| 描述 | 输入框 | 否 | 步骤说明 |

### 6.7 断言字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 类型 | 下拉选择 | 是 | 元素存在/文本等于/文本包含/文本不包含/属性等于/属性包含/输入框值等于/正则匹配 |
| 元素 | 元素选择器 | 条件 | element_exists 时不需要 |
| 期望值 | 输入框 | 否 | 期望值 |
| 描述 | 输入框 | 否 | 断言说明 |
