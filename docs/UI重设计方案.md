# APP 自动化测试平台 — UI 重设计方案

> 版本: v1.0  
> 日期: 2026-08-20  
> 状态: 待实施

---

## 1. 设计目标

打造一个 **现代 SaaS 风格** 的测试平台 UI：
- 清爽、专业的视觉感受
- 一致的设计语言（颜色/间距/圆角/阴影）
- 良好的信息层级和操作引导
- 保留 Element Plus 组件库，仅通过样式覆盖实现

---

### 5.2 设计要点

- **卡片式布局替代表格**：每个项目显示为一张卡片，信息更丰富
- **卡片内容**：项目名称、描述标签（公开/私有）、可见性图标、创建时间、角色、操作按钮
- **双击卡片**进入项目（等同于点击"进入"按钮）
- **操作按钮**在卡片右下角，文字按钮风格
- **筛选栏**：搜索框 + 可见性 Radio Button，统一圆角背景
- **分页器**居右

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 名称 | 输入框 | 是 | 项目名称 |
| 描述 | 文本域(3行) | 否 | 项目描述 |
| 可见性 | 单选(私有/公开) | 是 | 默认私有 |

### 6.5 编辑器设计要点

- 步骤/断言卡片用**左侧彩色竖线**区分（步骤蓝色、断言绿色）
- 拖拽手柄 `⠿` 放在最左侧，hover 时变主色
- 每个步骤/断言有圆形序号徽章 ① ② ③
- 删除按钮用红色文字，hover 出确认提示
- 底部固定操作栏：返回 + 保存

### 6.6 执行步骤字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 动作 | 下拉选择 | 是 | 启动APP/关闭APP/点击/输入/清空/滑动/滚动/返回/等待/截图/获取文本/获取属性/坐标点击 |
| 元素 | 元素选择器 | 条件 | sleep 时不需要 |
| 参数 | 输入框 | 否 | 根据动作类型不同 |
| 描述 | 输入框 | 否 | 步骤说明 |

### 6.7 断言字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 类型 | 下拉选择 | 是 | 元素存在/文本等于/文本包含/文本不包含/属性等于/属性包含/输入框值等于/正则匹配 |
| 元素 | 元素选择器 | 条件 | element_exists 时不需要 |
| 期望值 | 输入框 | 否 | 期望值 |
| 描述 | 输入框 | 否 | 断言说明 |

### 9.3 变量创建/编辑弹窗

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 变量名 | 输入框 | 是 | 编辑时禁用 |
| 值 | 输入框 | 否 | 变量值 |
| 描述 | 文本域(2行) | 否 | 变量描述 |
