## 1. 执行原则

- 严格按 Step 1 → Step 12 顺序实施；后续 Step 可以依赖前序接口，禁止跨 Step 留半成品。
- 一个 Step 内列出的后端、Agent、前端、迁移和文档子任务全部完成后，才执行该 Step 的完整门禁。
- 涉及数据库的 Step 必须先生成迁移、人工审阅迁移，再执行 `upgrade head` 和 `alembic check`。
- 不在 FastAPI 中实现 Worker 的终态汇总职责；FastAPI 只请求停止或修复明显的陈旧锁，报告汇总与正常设备释放仍由 Worker 完成。
- 新增或修改公开 API 时，同时更新 Pydantic schema、前端 TypeScript 类型、接口测试和权威设计文档的增量说明。
- 每个 Step 门禁全部通过后提交一次；提交信息使用本文给出的固定格式。

### Agent URL 代码

- [ ] 修改 `agent/main.py`：
  - 将 `http_base_url()` 重命名为 `http_origin()`。
  - 使用 `urllib.parse.urlsplit` 解析 URL，只接受 `ws`、`wss`。
  - `ws → http`、`wss → https`，保留完整 `netloc`，丢弃 path/query/fragment。
  - URL 缺少 hostname、包含用户名密码或 scheme 非法时抛出 `ValueError`，启动日志给出可操作错误。
  - `build_agent_app()` 和 `main()` 创建 `BindingManager`/`Uploader` 时统一调用 `http_origin()`。

参考实现形状：

```python
def http_origin(ws_url: str) -> str:
    parsed = urlsplit(ws_url)
    if parsed.scheme not in {"ws", "wss"} or not parsed.hostname:
        raise ValueError("server 必须是有效的 ws:// 或 wss:// 地址")
    if parsed.username or parsed.password:
        raise ValueError("server URL 不允许内嵌凭据")
    scheme = "https" if parsed.scheme == "wss" else "http"
    return urlunsplit((scheme, parsed.netloc, "", "", ""))
```

### 强制释放 API

- [ ] 在 `backend/app/schemas/agent.py` 新增：

```python
class DeviceReleaseResponse(BaseModel):
    action: Literal["released", "stop_requested", "finalization_pending"]
    device: DeviceOut
    execution_id: int | None = None
    execution_status: str | None = None
```

- [ ] 重写 `POST /api/devices/{id}/release`：
  - `FOR UPDATE` 锁 Device。
  - 无 locked execution：根据 Agent在线状态设 idle/offline，返回 released。
  - locked execution为 queued：原子取消 queued并清锁，返回 released。

  - 已终态且 finalized：清陈旧锁，根据 Agent在线状态设 idle/offline，返回 released。
